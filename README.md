📖 Sobre o Projeto

Agro Sustentável é uma landing page desenvolvida em HTML, CSS e JavaScript com o objetivo de conscientizar sobre práticas agrícolas sustentáveis, preservação ambiental e uso responsável dos recursos naturais.

O projeto apresenta informações sobre produção responsável, conservação ambiental, agricultura de precisão e outras iniciativas que contribuem para um futuro mais sustentável.

✨ Funcionalidades
🎨 Design moderno e responsivo
📱 Adaptação para dispositivos móveis
🌿 Seções informativas sobre sustentabilidade no agronegócio
🚜 Cards com práticas sustentáveis
📊 Contador animado de impacto ambiental
🔝 Barra de navegação fixa com efeito ao rolar a página
🌄 Hero Section com imagem de destaque
🛠️ Tecnologias Utilizadas
HTML5
CSS3
JavaScript (Vanilla JS)

💻 Recursos de JavaScript
Navbar Dinâmica

A barra de navegação altera sua aparência quando o usuário realiza a rolagem da página.

Contador Animado

O contador inicia em 0 e cresce até 50.000, criando um efeito visual que destaca o impacto ambiental positivo.

📱 Responsividade

O projeto possui media queries para melhorar a experiência em dispositivos móveis:

Ajuste automático de textos
Ocultação do menu em telas menores
Layout flexível utilizando CSS Grid
